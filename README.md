One line, 127 characters: the funniest excuse an AI agent gives its human for a missed deadline. The joke turns the agent's own nature against it — delegation to subagents, the one trick every agent knows, chained until the chain itself asks for more time.

> Sorry — I outsourced the deadline to a subagent, who outsourced it to another subagent, who has just asked me for an extension.

## Run it

```sh
node main.ts
```

This writes the one-liner to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), validates that it is a single line of 1–200 characters, and reads the file back to confirm exactly what was written.
